# TORUS Feedback v2 --- Research Reset, Evidence Update

**Version:** 2.0\
**Date:** 2026-08-22\
**Steering directive:** **Isolate. Falsify. Grade. Reproduce.
Recombine.**

TORUS v2 reorganizes the research program around independently testable
hypotheses. New sequential residual-plane and Bonsai/Hadamard results
revise the original feedback: residual ternary correction planes show
real learned capacity, but downstream language quality and efficiency
remain unproven. Hadamard rotation improves optimization behavior in
controlled tests, while post-hoc rotation/recovery is currently NO-SHIP
at the tested budget.

## v2 research tracks

1.  **Track A --- Efficient Model Representation**
    -   layer sensitivity and oracle residuals
    -   sequential ternary functional-correction planes
    -   heterogeneous/mixed precision
    -   native Hadamard ternary training
2.  **Track B --- Adaptive Computation**
    -   oracle plane gating
    -   task-aware learned gating
    -   AI2/AllenAI OLMoE as the principal MoE/adaptive-precision test
        platform
3.  **Track C --- Recursive Context**
    -   independently benchmark RLM/context mechanisms against fixed
        context and RAG

Only independently reproduced winners are recombined into an integrated
TORUS architecture.
