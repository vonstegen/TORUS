# TORUS Three-Track Research Plan v2

## Program structure

### Track A --- Efficient Model Representation

Question: Can low-cost ternary or heterogeneous representations preserve
useful language behavior at a competitive quality-cost point?

Subtracks: - A1 layer/module sensitivity; - A2 oracle residual and
equal-storage alternatives; - A3 sequential functional-correction
planes; - A4 heterogeneous layer precision; - A5 native Hadamard ternary
training.

### Track B --- Adaptive Computation

Question: Can TORUS spend additional computation only where it produces
task-relevant value?

Subtracks: - B1 oracle T1 vs T1+T2 gating; - B2 task-aware learned
gating; - B3 OLMoE expert-routing × precision-routing experiments; - B4
realized latency/energy measurement.

### Track C --- Recursive Context

Question: Can recursive external context improve effective long-context
capability and economics for small/local models?

Subtracks: - C1 retrieval accuracy; - C2 long-document QA; - C3 RLM vs
conventional RAG; - C4 model-size scaling; - C5 tokens/compute/latency
economics.

## Integration gate

No subsystem is integrated merely because its code works. Integration
requires an independently reproduced PASS under the v2 grading rubric.
