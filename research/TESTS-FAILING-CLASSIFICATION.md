## Dev-box failure categorization

### Category A: triton not installed (14 tests)

| Test file | Count | Error |
|---|---:|---|
| `tests/test_af2_driver_extension.py` | 11 | `ModuleNotFoundError: No module named 'triton'` |
| `tests/test_t2_ternary_adapter_construction.py` | 3 | `subprocess failed: ModuleNotFoundError: 'triton'` |

**Root cause**: `examples/af2_storage_tournament.py` does `import triton`
at module top-level (line 15). On Legion, `triton` is installed; on
the dev box, `triton` is **not** part of `pyproject.toml`'s
`[project.dependencies]` and was never installed in the dev-box venv.

**Stable IDs**: `TEST-FAIL-{triton:01..14}` (one per failing test).

**Resolution**: either (a) install triton in the dev-box venv, or
(b) make the `import triton` lazy / optional in
`examples/af2_storage_tournament.py`. Resolution does NOT block RPM
evidence because Legion has triton and the experiments run there.

### Category B: SIMD kernel shared object not built (5 tests)

| Test file | Count | Error |
|---|---:|---|
| `tests/test_kernels_real.py` | 5 | `OSError: /tmp/TORUS/torus/kernels/build/libtorus_kernel.so: cannot open shared object file` |

**Root cause**: `tests/test_kernels_real.py` requires the SIMD kernel
shared library to be built (`torus/kernels/build/libtorus_kernel.so`).
The build is not run on the dev box; the .so is gitignored and only
generated by Legion's build setup.

**Stable IDs**: `TEST-FAIL-{kernel:01..05}` (one per failing test).

**Resolution**: build the kernel on the dev box. Resolution does NOT
block RPM evidence because the SIMD kernel is an **untouched** code
path for Stage 1 / 1.5 / 2 / 4 / 5 — the AF2-D and L15 results use
the reference PyTorch path, not the SIMD path.

### Category C: collection errors (3 files)

| Test file | Error |
|---|---|
| `tests/test_af1_budget_control.py` | collection failed (transitive triton import) |
| `tests/test_af2_damaged_ptq.py` | collection failed (transitive triton import) |
| `tests/test_af2_storage_tournament.py` | collection failed (transitive triton import) |

**Root cause**: same as Category A — `examples/af2_storage_tournament.py`
triton import cascades to test collection.

**Stable IDs**: `TEST-FAIL-{triton:15..17}` (one per file).
